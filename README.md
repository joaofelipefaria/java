# Java

This section contains Java-focused learning projects, from language features and design concepts to small backend samples and a multi-module microservices example.

## Projects

- calculator-w-tests: a small calculator sample with unit tests.
- java-concepts: examples covering collections, streams, lambdas, dates, I/O, reflection, and more.
- java-samples: miscellaneous Java examples.
- java-versions: examples showing language features introduced across Java versions.
- microservices-payment: a small multi-module microservices sample for payment-related operations.

## Technologies used across this repository

- Java 8+
- Spring Boot
- Maven
- Docker / Docker Compose
- PostgreSQL for the microservices example

## How to explore

Start with java-concepts or java-versions for language-oriented material, and use microservices-payment when you want to review a more complete backend architecture.
